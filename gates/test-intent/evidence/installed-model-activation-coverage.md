# Installed-model activation: A2–A4 coverage, repair round 2

Baseline: `7a6ab81ea11279008a853fa5574b11da4b051c02`. Candidate: **the repair commit containing this map**, whose production code is unchanged from `f00f25ff30`. Round 2 adds the four required source labels and repairs the help fixture, not a product or saved-value change. Test source digests and individual baseline/candidate cases are in [round-2 results](installed-model-activation-round2-results.json). [Repaired evidence](installed-model-activation-repaired.json) records 12 executed candidate cases and 12 baseline assertion failures. [Selected-suite evidence](installed-model-activation-preservation.json) records 176 executed candidate cases. An additional 45 existing recovery cases passed on both builds, bringing unique candidate cases to 229 (234 on the baseline, including five help-enumeration cases only selected there). None was skipped. Some selected classes contain both repaired and preservation methods; those are distinguished below.

The help fixture now calls `bindBootRootBindings(List.of())` before startup, exactly as `EngineRoot` does even for an empty registry. Without this binding, configured-root volume seeding cannot begin. The private evidence profile had put temporary files on a filesystem without stable volume identity and concealed this missing setup. Normal `/home` test resources expose it. The fixture uses the current `v4` help marker. The standard `test` invocation and the CI `ciUnitTest2` invocation pass on the candidate and fail on the baseline at the missing `justsearch-help` field assertion, not a timeout. All assertions and volume protections remain.

`R` means new/repaired behavior: fails before for the assertion under test, passes after. `P` means preservation: passes before and after. Rows labelled intended preservation but unverified have no paired live result. **Partial** identifies a passing narrower check; it does not certify the full scenario. **Unverified** means the required real-system check has no result on one or both revisions. No configured, queued, cached, or unexecuted case counts as a pass. An independent verifier still owns acceptance.

## Execution addendum and remaining constraints

The selected unit checks and 45 additional recovery checks were run serially through `js-gradle-slot ./gradlew`, shared `~/.gradle`, each checkout's own build directory and test resources. The baseline is a shared clone inside the task's temporary root; no source-tree stashing or reverting. `.agents/preflight` is absent. No GPU, VM, shared dev stack, sudo, install, push, tags or GitHub Actions were used by this repair.

Four installed-process candidate cases completed under fresh private state: `installer-before-marker`, `installer-before-arm`, `installer-before-pointer`, `installer-pointer-before-settings`.
