# `gates/test-intent/evidence/`

Execution evidence for new checks (tempdoc 966 D4), written by
`scripts/governance/gates/test-intent/run-evidence.mjs` after it ran the checks itself. Do not write
or edit these files by hand: the gate checks each file's self-digest and the content of every check
it names. See `docs/reference/testing/test-intent.md`.
