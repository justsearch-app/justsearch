# Test-intent entries

The NER lifecycle field changes from `deferCpuSession: false` (construct a CPU copy at
composition even when CUDA is selected) to `true` (construct that copy only when the first CPU
fallback needs it). This is the requested idle-start memory change, not snapshot regeneration
from implementation output. CPU-selected NER stays eager; GPU retry stays disabled. All other
snapshot values and the byte-for-byte comparison remain unchanged.

The fail-before run overlays only the new snapshot expectation on the unchanged baseline:
it rejects the old eager CUDA NER policy. The idle/fallback check separately rejects the old
session creation and checks a single reusable CPU session after first fallback.
