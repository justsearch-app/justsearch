R9 script checks (governance self-tests are outside the gate's D4 runner scope):

- `scripts/dev/test-dev-runner-linux-helper-census.mjs` and `scripts/dev/fixtures/rapid-tesseract-helper.jsonl` — New H1/H2 regression checks. Source: task t-20261017-9a5f5a user turn Round 9, H1: “a helper that the Engine itself started and awaited (exit code observed by the creator through its own process handle) is accounted as exited by stop, even when its birth identity could not be read”. H2 requires incomplete accounting without that same-writer, same-helper awaited code and forbids bare-PID signals. The exact two-line live fixture fails before at `tmp/r9/h1-before.log` and passes after at `tmp/r9/helper-census-final.log`; parser-owner binding and legacy retry recovery are asserted too. Durable.
- Only otherwise-valid missing/null-birth inventory and stop cases now omit a creator-observed exit code, preserving the H2 incomplete/no-signal/no-data-loss oracle. Malformed tuple/key cases retain their original code 0 fault injection so those validations remain independently asserted. Their former premise that even a complete creator receipt was unusable is explicitly replaced by H1, not called an unchanged oracle. Every Windows helper case stays unchanged.
- H3: production Java already captures the tuple immediately after ProcessBuilder.start in BoundChildProcess.spawn, before waiting for exec, retains it against the original Process weak key, and retries if absent. LinuxProcessTerminator.open reuses that birth. An extremely short child can still be reaped before either read; reading ProcessHandle.startInstant cannot recover an exact boot/start-ticks tuple safely. H1 is the fallback; no helper handshake, fabricated birth or timestamp is added.
- H4: owner-only forget/admission policy is unchanged. Ordinary stop already admits an ended owner's run; new logical receipt reconciliation clears that obligation, never grants OS/PID signal authority. Original run 677b22be was cleared by the fixed runner's ordinary stop in `tmp/r9/recover-stuck-second.json` with no signals. `tmp/r9/live-session.log` records Tesseract probe → stop → start → final stop.
