- **K6:** Each launch has a new key: bind-race retry on a fresh port, context-window step-down, reasoning-flag retry, crash recovery, Engine restart, online/offline and model switches all reach an authenticated working server; an obsolete key is rejected. - **K7:** An explicitly configured external endpoint works and never receives the managed server's key (its own configured authentication, if any, unchanged); an incidental healthy server stays ignored and unmanaged servers are not stopped.

- **K8:** If the key cannot be passed (environment rejected, binary refuses), the launch fails with a bounded, actionable error and the child is cleaned up; never an unauthenticated server.

- **K9:** Windows packaged desktop and CUDA variants: K1 and K4 (no Windows host).
