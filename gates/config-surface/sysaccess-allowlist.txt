# System-access allowlist — tempdoc 883 decision 5. One entry per line: `<fully.qualified.Class>#<member>`.
#
# WHAT THIS IS. Every direct read or write of process-global state — System.getenv,
# System.getProperty/setProperty/clearProperty/getProperties/setProperties, and their two disguises
# Boolean.getBoolean / Integer.getInteger — that lives OUTSIDE io.justsearch.configuration, the
# sanctioned funnel. `io.justsearch.deadcode.SystemAccessFunnelTest` (modules/dead-code-audit) fails
# the build on a site that is not listed here, and fails on a listed site that no longer exists.
#
# THESE ARE RECORDED, NOT BLESSED. Every line is a consumer reaching around the resolver, so it does
# not see settings.json, YAML, the worker snapshot, or a value that changed at runtime — it sees
# whatever was in the environment when the JVM started. Shrinking this list is the point. The
# `config-surface` gate additionally fails when the list GROWS without a declared changeset
# (rule config-surface/sysaccess-allowlist-growth), because appending a line is the one-line way to
# make the funnel test green without fixing anything.
#
# THE FIX for a new site is to declare the key in EnvRegistry and read it from ResolvedConfig (or
# SystemAccess for a genuinely process-global one) — not to add a line here.
#
# SEEDED from the six per-module ArchUnit rules this replaces
# (app-api/ArchitectureRulesTest, core/ArchUnitSanityTest, app-services/AppServicesWorkerGuardrailsTest,
# indexer-worker/IndexerWorkerGuardrailsTest, ui/UiApiGuardrailsTest, adapters-lucene/AdaptersLuceneGuardrailsTest)
# plus the nine modules their union never covered: telemetry, app-inference, gpu-bridge, ai-backend,
# app-launcher, ort-common, worker-services, benchmarks, ssot-tools.
#
# Reasons carried over from the retired rules' inline exemptions:
#   - indexerworker.server.DevReloadManager — dev-only build-stamp updater (tempdoc 371).
#   - indexerworker.services.IndexStatusOps — reads the stamp via EnvRegistry indirection (371).
#   - indexerworker.services.WorkerHealthService — JUSTSEARCH_WORKER_HEALTH_SYNTHETIC_DELAY_MS, a
#     test-only synthetic-delay hook, default 0/off (374 alpha.25 R13-A).
#   - workerservices/indexerworker extract.TikaOcrRuntime — native-resource DISCOVERY (locating the
#     bundled/system Tesseract binary and tessdata via PATH/APPDATA/LOCALAPPDATA/TESSERACT_PATH/
#     TESSDATA_PREFIX, and os.name for the platform binary name). This probes the WORKER HOST's
#     filesystem, which the Head's config snapshot cannot know (tempdoc 607). Owned by lane C.
#   - app.services.bootstrap.phases.* / HeadAssembly / BootstrapHelpers — bootstrap entrypoints that
#     run before a ResolvedConfig exists.
#   - app.services.bootstrap.phases.ExamplePlugin — a demo/dev enable toggle, not application config
#     (tempdoc 560 §10.4).
#   - app.services.lease.OperationLeaseServiceImpl — dev-runner signals.
#
# Note on member names: a lambda body is attributed to the method that declares it
# (javac's `lambda$foo$3` is normalised to `foo`), because the index shifts on unrelated edits and a
# ratchet that cries wolf gets deleted.
#
