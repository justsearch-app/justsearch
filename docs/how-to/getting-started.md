# Get started with JustSearch

When Search says **Nothing to search yet**, choose **Add a folder**, or choose a suggested
folder by its name and path. On desktop, select a folder in the native picker; in a browser,
enter the folder's path on the computer running JustSearch and choose **Add**. Viewing a
suggestion does not add it. Cancelling changes nothing. If a path is unavailable or overlaps
a watched folder, correct it or choose another folder and retry.

Search becomes usable as soon as the first files are read. “n files searchable so far” is the
number currently available to search. “m waiting to be read” describes the observed queue,
which can grow while JustSearch finds more files. If a watched folder produces no searchable
files, open **Library** to check what is being read, skipped or failing.

The Getting started card tracks adding content and trying a search. The last step, **Optional:
answers and search by meaning**, opens AI Brain; opening the card does not download models.
Keyword search works without AI models or supported AI hardware. The core card goes away
after the first two steps finish. Plugin walkthroughs can still appear in its place.

Choose **Hide** to put Getting started away. Open **Help → Getting started** to bring it back;
it then stays until you hide it. This choice survives reload, applies across windows and is
shared across profiles. A completed factory reset starts fresh.
